# 🤖 Telegram AI Bot & Web Admin Panel

A feature-rich Telegram bot powered by **Google Gemini AI (Gemini 3.6 Flash)** with a built-in **Flask Web Panel** for managing dynamic message footers.

## ✨ Features
* **AI Integration:** Uses Google Gemini to chat naturally with users (configured with a Tsundere persona!).
* **Group & Private Chat Support:** Handles direct messages and group mentions (`@Terminator_b_bot`).
* **Web Admin Panel:** A secure Flask-based dashboard for administrators to update the bot's HTML footer in real-time.
* **Robust Connection Handling:** Built with auto-retry mechanisms and custom timeouts for network stability (optimized for cloud platforms like PythonAnywhere).

## 🛠️ Tech Stack
* **Python**
* **python-telegram-bot**
* **Google Generative AI SDK**
* **Flask** (Web Framework)
